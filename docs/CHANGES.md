# Azar Play: 이전 얼라인 대비 변경 사항 (2026-10-20)

HANDOVER.md 시점(Figma와 Notion에 반영된 내용)과 비교해서, 그 뒤 Philo와 정한 것과 프로토타입에 구현된 것을 정리한 문서입니다. 피그마와 Notion을 이 문서 기준으로 고칩니다. 시연 웹은 피그마 껍데기와 픽셀 단위로 맞출 예정이라 **피그마가 원본**입니다.

마감: 2026-10-21(수) 18:00. 제출물은 전부(플레이 가능한 링크, 피그마, 시연 영상, Notion 문서).

## 1. 방과 시간
- 한 판 30초 + 결과 후 리액션 약 30초. **방은 게임 시작 시점부터 1분 후 만료.**
- 이전: "한 판이 1분 이내". (R1은 "방이 1분 안에 끝난다"로 해석)
- 결과 후 방이 닫히기 전에 **"이 사람과 비디오챗으로"** 또는 **"한 판 더"** 버튼. 수익화 포인트. 프로토타입에서는 화면과 흐름만 만들고 결제는 연결하지 않음.
- "한 판 더"를 둘 다 누르면 새 1분 방으로 이어짐.
- 결과 후 리액션: 영상으로 서로 반응 + 이모지 리액션 4종(👏😂😭🔥)이 상대 칸/내 칸 위로 떠오름.

## 2. 웃음 참기 (대표 데모)
- 동시형. 시작 전 3초 카운트다운 동안 무표정 기준선 자동 측정(2초).
- **필터가 3~4초(구현은 4초)마다 바뀜.** 이전 안(10초마다 3단계 상승)은 폐기.
- 필터는 **얼굴 부위별 변형 + 표정 반응형**(입 벌림, 미소, 깜빡임에 따라 커짐). 얼굴 타원 안쪽에서만 적용하고 배경은 그대로. 6종: 왕입 외계인, 왕코 외계인, 풍선 볼, 쭉 턱, 왕이마 외계인, 콩알 얼굴. 두 사람은 **서로 다른 필터** 순서를 받고 같은 순간에 같은 필터가 겹치지 않음.
- 필터는 영상에 합성되어 **상대도 변형된 얼굴을 봄.**
- **목소리 변조**: 필터가 바뀔 때마다 목소리도 바뀜(낮음, 높음, 헬륨, 로봇, 다람쥐). 상대 귀에 나감.
- 승패:
  - 웃음 점수가 계속 쌓임(한 번 웃는다고 지지 않음). 점수가 **낮은 쪽이 승리**(차이 2점 미만이면 무승부).
  - **에너지(HP)가 먼저 바닥나면 즉시 패배**("에너지가 다 닳았어요! 졌어요!"). 거의 동시(0.4초)면 무승부.
  - 30초를 버티면 점수 비교.
- HUD: 화면 위 HP 바(초록→빨강, 흰 잔상이 따라 내려옴), 내 웃음 점수와 상대 웃음 점수 막대, 남은 시간, 내 필터와 상대 필터 이름, 방 닫힘까지 남은 시간.
- 맞을 때 연출(영상에 그려져서 상대도 봄): 머리 위에 작은 별 폭발과 "-숫자", 화면 흔들림, 붉은 가장자리 번쩍임, 집중선, 작은 충격파와 불꽃, 점수가 쌓일수록 화면에 금이 늘어남, 머리 위로 도는 ⭐. 얼굴은 가리지 않음.
- 결과 문구: 이겼어요! 덜 웃었어요 / 졌어요! 더 많이 웃었어요 / 에너지가 다 닳았어요! 졌어요! / 이겼어요! 상대 에너지가 바닥났어요 / 무승부 / (혼자 해보기) 끝까지 해냈어요!

## 3. 규칙 변경
- **R13 완화**: 얼굴을 늘리고 줄이는 변형, 억울한 표정 같은 과장된 연출은 허용. **인종, 성별, 특정 집단을 연상시키는 표현(눈 찢기 같은 제스처, 얼굴 특징의 고정관념화)과 패자 비하 연출은 제외.**
- 눈 짝짝이 필터는 제외(별로라서).

## 4. 화면 구성에 영향
- 내 칸과 상대 칸은 정방형 유지. 상대 칸은 필터가 합성된 영상.
- 녹화: 내 화면만 저장하는 기본 정책에서 저장되는 영상은 필터와 이펙트가 입혀진 영상.
- 마이크가 켜짐(목소리 변조). 이어폰 권장(에코).
- 얼굴을 가리지 않는 것이 이펙트의 원칙.

## 5. 프로토타입 한정(실제 제품과 다름)
- 매칭은 고정 자리 2개(1번, 2번)에 먼저 들어온 두 명이 연결되는 방식. 세 번째는 "자리가 꽉 참" 안내 후 자동 재시도. 실제 제품의 랜덤 매칭이나 Discover 연동은 시연에서 화면으로만 표현.
- LTE 등 다른 네트워크 간 연결은 미지원(TURN 서버 없음). 같은 Wi-Fi 기준.
- 판정은 각자 기기에서 하고 서버는 없음.

## 6. 확정 결정과의 충돌 (고칠 것)
- "둘 다 Ready를 누르기 전에는 어떤 영상도 송출하지 않는다"가 확정 결정인데, 프로토타입은 연결 즉시 영상이 상대에게 감. → 둘 다 준비하기 전에는 검은 화면을 보내도록 수정 예정.

## 7. 다른 게임 (예정)
- 필수 데모 구성은 표정 1 + 소리 1 + 모션 1. 순서: 웃음 참기(완료) → 고진감래(표정+모션) → 납작 날씬 아주주(소리, 에코 시험 필요) → 무궁화꽃(이번엔 제외).
